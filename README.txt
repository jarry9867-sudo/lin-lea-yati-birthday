LIN LAE YATI TUN — BIRTHDAY WEBSITE

1) Add four photos into this same folder and name them exactly:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   photo4.jpg

2) Open index.html in a browser to preview the site.

3) To publish with GitHub Pages:
   - Create a new public GitHub repository.
   - Upload index.html and the four photo files to the repository's main/root folder.
   - Open Settings > Pages.
   - Under Build and deployment, choose Deploy from a branch.
   - Select branch: main; folder: /(root); then Save.
   - Wait for GitHub Pages to publish and copy the website URL.

Note: This is a static website. The music feature is intentionally not included yet; if you want background music, add a legally usable audio file and a player control.
